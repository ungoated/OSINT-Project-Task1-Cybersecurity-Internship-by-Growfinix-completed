# OSINT Project - Task 1

**Cybersecurity Internship by Growfinix**  
**Student:** Mohit Kumar

This project demonstrates a passive OSINT and surface-reconnaissance workflow using publicly available domain, DNS, and certificate information.

## Included files

- `REPORT.md` - task objective, methodology, findings, analysis, and recommendations
- `COMMANDS.md` - commands used with short descriptions
- `Screenshots/` - command-output evidence

## Ethical boundary

Only passive public-information sources were used. No port scanning, login attempts, exploitation, brute force, credential collection, or active validation was performed.
